# Code of conduct

Be respectful. Discuss the work, not the person. Harassment, insults,
discrimination and publishing other people's private information are not
acceptable anywhere in this project: issues, pull requests, reviews or chat.

Maintainers may edit or remove contributions that break these rules and may
block repeat offenders. Report a problem privately through GitHub: open a
private security advisory on this repository, or contact a maintainer through
their GitHub profile. Reports are handled in confidence.

This code applies in all project spaces and when someone represents the project
in public.
